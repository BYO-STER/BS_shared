이 폴더는 BS calendar 프로젝트에서 배포되는 공유 일정 웹페이지입니다.

원본은 BS_calendar/webshare 이고, 여기 있는 파일은 그 사본입니다. 이 저장소에서 직접 고치면
다음 배포 때 덮어써집니다. 고칠 일이 있으면 원본을 고친 뒤 다시 배포해 주세요.

lib 폴더는 PC 앱의 서버 동기화 로직을 자동 변환한 사본입니다. 사람이 손으로 고치지 않습니다.

이 페이지는 로그인한 구글 계정이 볼 수 있는 공유 캘린더와 시간 조율만 보여줍니다. 권한은
서버의 정책이 정하며 이 페이지가 따로 갖는 권한은 없습니다. config.js 에 들어 있는 키는
클라이언트에 공개되는 것을 전제로 만들어진 공개 키입니다.
